### Why a request can return `total: 0`

The search endpoint validates three things and answers **HTTP 200 with
`total: 0`** when any is missing — it does not return an error:

1. header `X-Requested-With: XMLHttpRequest` (this is the one that is easy to miss)
2. form field `solrType=TITLE` (not a numeric id, not `anyword`)
3. form field `xiaoqu=all` (an empty value yields no results)

Full working form body:

```
xiaoqu=all&keyword=<kw>&solrType=TITLE&pageNo=1&pageSize=10&classSearch=0&searchPrecision=
```

A browser-shaped `User-Agent` and a `Referer` of
`https://opac.bupt.edu.cn/search-full-result.html` are also required.

### Holdings table shape (2026-11)

Each `<tr>` has 9 `<td>` cells:

```
0 馆藏部门 | 1 图书条码 | 2 索书号 | 3 登录号 | 4 架位导航 | 5 卷期 | 6 状态 | 7 操作 | 8 空
```

Status lives in cell **6** (`在架可借`, `借出`, …); cells 4 and 7 are action
links (`架位导航`, `异地预借`) — do not mistake them for status.
